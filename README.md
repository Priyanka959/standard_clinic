A modern, high-performance, responsive web application for a premier dermatology clinic. Built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, featuring a beautiful, elegant UI/UX design tailored for healthcare professionals and premium aesthetic services.

## ✨ Features

- **Modern & Premium Design**: Clean, sophisticated interface using elegant typography and a calming color palette (Sand, Brown, Charcoal, and Cream).
- **Responsive Layout**: fully mobile-optimized, prioritizing touch interactions while gracefully scaling up to ultra-wide desktop displays.
- **Hardware-Accelerated Animations**: Smooth scroll reveals, parallax image effects, infinite marquees, and 3D carousels powered by Framer Motion and native CSS.
- **Dynamic 3D Gallery**: Interactive, responsive image carousel natively handling layout transitions without performance drops.
- **Continuous Testimonial Marquees**: Elegant, animated patient reviews seamlessly spanning across the page smoothly.
- **Smart Color Switching Navbar**: Header adapts dynamically depending on scroll position and dark/light page variants.
- **Interactive SVG Overlays**: Fully coded geometric embellishments designed exactly to specification without bulky image assets.

## 🚀 Tech Stack

- **Frontend Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & CSS Keyframes
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 📂 Project Structure

- `/frontend/app`: Next.js App Router pages (`/`, `/about`, `/services`, `/contact`, `/faq`, `/blog`, `/treatments/[slug]`).
- `/frontend/components/sections`: Fully modular and responsive sections (Hero, About, Gallery, Testimonials, etc.).
- `/frontend/components/common`: Shared layout components (Navbar, Footer, PageHeroBanner).

## 💻 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Priyanka959/standard_clinic.git
   cd standard_clinic/frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Navigate to:** [http://localhost:3000](http://localhost:3000)

## 🎨 Deployment

Easily deployable on platforms like [Vercel](https://vercel.com/) natively integrating Next.js scaling out-of-the-box.
